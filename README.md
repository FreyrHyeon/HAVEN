# HAVEN

로엔·유리아·세린·리에라가 함께하는 4인 버추얼 그룹 HAVEN의 공식 홈페이지.

공개 주소: https://freyrhyeon.github.io/HAVEN/

- index.html: 메인
- members.html: 멤버 소개
- world.html: 세계관과 네 멤버의 능력
- content.html: 음악·콘텐츠 소식
- channels.html: 공식 채널

리틀 HAVEN의 집합·산책, 드래그·만남·사진 반응·능력 반응을 제공합니다. 로엔의 상세 소개는 항목 선택과 전체 읽기를 지원합니다. 원화의 표정 전환과 공식 채널 스와이프·키보드 탐색을 유지합니다. 음악은 아직 공개 준비 중입니다. 리틀 HAVEN은 멤버별 16개 포즈 프레임과 상황별 말하기·시선·생각·걷기·달리기, 네 가지 능력 연출을 사용합니다. 로엔의 여우·고양이 신수, 유리아의 푸른 새 세 형제, 세린의 흰색·검은색 고양이와 리에라의 별 정령이 따라다닙니다. 오른쪽 별도 이모티콘 배지는 표시하지 않습니다.

GitHub Pages main 브랜치 루트 배포. canonical·JSON-LD·sitemap.xml은 각 실제 페이지 URL을 사용합니다. 분석은 GTM-NB4JPC3V 단일 경로이며 로컬 미리보기에서는 보내지 않습니다.
